# 记忆脑图（panel）

一个纯静态的 WebGL2 可视化：把 `memory_brain` 里的记忆画成一座会呼吸的脑。

## 打开

```bash
# 1) 生成数据（只读 bot.db）
python panel/tools/build_data.py
# 2) 浏览器打开
panel/index.html
```

没有 `data.real.js` 时会自动回落到 `data.demo.js`（合成数据），所以 clone 下来直接双击也能看。

### 实时模式

```bash
python tools/panel_server.py          # 在仓库根目录跑
# 打开 http://127.0.0.1:8090/?live=1
```

每 3 秒拉一次 `/api/state`：人格卡、记忆数、构成条跟着库变；
记忆条数变化时整页刷新一次以重建场景。

## 能看到什么

| 区域 | 内容 |
|---|---|
| 中央 | 14 个脑区、记忆之湖、检索光束、人格内核 |
| 左上 | 皮层导航小地图：雷达扫描、相机视锥、点选飞入并隔离 |
| 左下 | 记忆构成：按类型堆叠，可点选只亮某一类 |
| 右上 | 人格内核：亲密度环、PAD、能量、五维雷达 |
| 右下 | 认知流（示例文案） |
| 底部 | 48h 时间轴、视角/显示/质量/检索/导出 |

记忆湖里每颗点就是一条记忆：**R 越低越小越暗**，已归档的是灰暗环。

## 交互

- 拖拽旋转、滚轮缩放、`空格` 暂停自动巡航、`R` 复位、`F` 全屏
- 悬停节点看内容，点击固定；`/` 聚焦搜索框
- 质量 高/中/低：低配机器也能跑

## 构建单文件版

```bash
python panel/build_single.py   # → 小小记忆脑图.html（CSS/JS 全内联，拷走就能开）
```

## 技术要点

- 无构建步骤、无依赖、无网络请求；`js/*.js` 是普通脚本（不是 ES module）
- 后处理链路：亮部提取 → 高斯 → ACES → 颗粒/暗角/色散
- **全屏后处理必须 `disable(BLEND)`**，否则加性混合会跨帧累积成白屏
- 节点字形用 SDF 在 fragment 里画，缩放不糊
