# 小小 · 速查卡（精简版）

> 详细版：`docs/小小-接入与交接-详细版.md`

## 三样东西

| | 作用 | 位置 |
|---|---|---|
| 机器人 | 聊天 + 记忆读写 | `qq-soul/`（`start_bot.bat` 启动） |
| 数据库 | **唯一真相**，她记不记得全看它 | `qq-soul/data/bot.db` |
| 面板 | 只读可视化（不参与对话） | `panel/小小记忆脑图.html` |

## 面板

打开：双击 `小小记忆脑图.html`（或 `index.html`，需旁边有 `style.css` + `js/`）
刷新数据（改完才会动）：

```bat
cd C:\path\to\qq-soul
python panel\tools\build_data.py && python panel\build_single.py
```

功能：3D 脑区 / 记忆之湖（点按保持度 R 变暗）/ 小地图导航 / 记忆构成过滤 / 检索 / 时间轴回放 / 导出 PNG。

## 记忆怎么走

- **写**：每轮回复后 `growth.reflect` 抽记忆 → 去重合并 → 记 `stability`（稳定度）和 `region`（分区）
- **读**：每轮前 `search_memories` = 关键词 × 保持度 R × 权重，分区命中加权，预算 320 tok
- **忘**：`R = exp(-Δt/S)`，90 天没碰且 R<0.05 的归档（不删，仍可查）

## 接实时（推荐：本机小服务）

1. `python tools/panel_server.py`（静态托管 `panel/` + `/api/state` 返回 SQLite 快照），`127.0.0.1:8090`
2. `js/main.js` 里加 `?live=1` 时每 3 秒 `fetch('/api/state')`，更新数字/人格卡；记忆条数变了才重建场景
3. 打开 `http://127.0.0.1:8090/index.html?live=1`（必须 http，file:// 不能 fetch）

不想写代码：计划任务每 60 秒跑 `build_data.py` + 页面加 `<meta http-equiv="refresh" content="30">`。

## 换窗口

**她换窗口（重启/换模型）→ 不会失忆**
记忆在 `bot.db`。`start_bot.bat` 重启即可；换模型用 `tools\set_llm.py --base … --model … --key … --test`，再重启。

**你换 AI 编码窗口 → 用交接包**
新对话粘这段：

```text
项目 C:\path\to\qq-soul（QQ 机器人「小小」，Python+SQLite+DeepSeek），
面板 C:\path\to\qq-soul\panel。
先读 docs/小小-接入与交接-详细版.md、方案.md、bot/{store,engine,persona,growth,forgetting,brainmap}.py。
硬约束：bot.db 是唯一真相，改库前先备份到 backups/；不改 13 条规则语义；
静态块必须在 prompt 最前；后处理必须 disable(BLEND)。
先只读，汇报现状，别动文件。
```

**从零重建**：拷 `qq-soul/`（含 `.runtime`、`data/bot.db`+`-wal`+`-shm`、`persona.json`、`config.json`）→ `tools\start_napcat.ps1` → `start_bot.bat` → 发 `#状态` 验收。

## 三个高频故障

| 现象 | 原因 | 处理 |
|---|---|---|
| 发消息没反应 | NapCat 掉线 / bot 没起 | 看 `logs\bot.log` 有无「OneBot 已连接」；重开 `start_napcat.ps1` |
| 面板白屏/未样式化 | 打开了分文件版但缺 css/js | 用单文件版 `小小记忆脑图.html` |
| 她"失忆" | db 被换 / 路径变了 | 默认路径是 `data/bot.db`（除非 config 里配了 `paths.db`）；从 `backups/` 恢复后重启 |
