# 接入你自己的模型

bot 只认一种接口：**OpenAI 兼容的 `POST {base_url}/chat/completions`**。
所以只要把你的模型包成这个接口，改三行配置就能换上，不用动 bot 代码。

---

## 一、先看 bot 怎么发请求

```
POST {base_url}/chat/completions
{
  "model": "...",
  "messages": [{"role":"system",...},{"role":"user",...}],
  "temperature": 0.95,
  "max_tokens": 400,
  "response_format": {"type": "json_object"}   // 部分服务不支持，可忽略
}
```

期望返回：

```json
{"choices":[{"message":{"content":"{\"messages\":[\"嗯\"]}"},"finish_reason":"stop"}]}
```

`content` 必须是一段 **JSON 字符串**（bot 会容错去掉代码块再解析）。

### C. 自己写的 Python 服务（你训练/加载的模型）

```python
# server.py
from fastapi import FastAPI
from pydantic import BaseModel
import uvicorn

app = FastAPI()

class Req(BaseModel):
    model: str = "local"
    messages: list
    temperature: float = 0.9
    max_tokens: int = 400

@app.post("/v1/chat/completions")
def chat(req: Req):
    system = "".join(m["content"] for m in req.messages if m["role"] == "system")
    user = "".join(m["content"] for m in req.messages if m["role"] == "user")
    out = my_generate(system, user, max_new_tokens=req.max_tokens)   # ← 换成你的推理
    return {
        "id": "x", "object": "chat.completion",
        "choices": [{"index": 0, "message": {"role": "assistant", "content": out},
                     "finish_reason": "stop"}],
        "usage": {},
    }

if __name__ == "__main__":
    uvicorn.run(app, host="127.0.0.1", port=8082)
```

```bat
.runtime\python\python.exe tools\set_llm.py --base http://127.0.0.1:8082/v1 --model local --key x --test
```

## 三、上下文不会「满」

bot 从来不会把整段历史一次性丢给模型。每次请求只带：

- 人设 + 当前状态（心情/精力/亲密度）
- 召回的 3–6 条长期记忆
- 昨天的日记片段
- **最近 N 条对话**（默认 10，可调）
- 当前这句话

所以「窗口满」在 bot 侧不会发生：短期靠滚动窗口，长期靠记忆库。
你的模型上下文小，就把 N 调小：

```bat
.runtime\python\python.exe tools\set_llm.py --small-context
```

预设：历史 4 条、记忆 3 条、prompt 上限 3000 字。

`bot/persona.py` 里还有一层保护：prompt 超过 `max_prompt_chars` 时，从最旧的对话开始丢，保证不超预算。

## 四、小模型的现实问题

| 问题 | 表现 | 对策 |
|---|---|---|
| JSON 不稳 | 多写解释、格式坏 | 已有 3 次重试 + 容错解析；仍不行就换大一点的模型 |
| 人设漂移 | 越来越像客服 | 提高 system 权重、`temperature` 降到 0.7 |
| 上下文短 | 记不住前文 | `--small-context`，并让记忆库多存事实 |
| 回复慢 | 打字延迟叠加 | 调小 `humanize.per_char`，或换量化版 |

改完先自测，再重启：

```bat
.runtime\python\python.exe tools\set_llm.py --test
```

`--test` 会真的发一次请求，验证服务在跑、模型名对、JSON 能解析。

## 六、注意

- 改完配置要**重启 bot**（watchdog 一分钟内会自动拉起，或手动 `run.bat`）。
- 不要用 `start_napcat.bat` 那套 cmd 方式起 NapCat，登录后会卡住；用 `tools\start_napcat.ps1`。
- 如果模型支持 `response_format=json_object` 最好；不支持也没关系，prompt 里已经要求只输出 JSON。
